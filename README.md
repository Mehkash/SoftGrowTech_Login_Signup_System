# Login & Signup System (GUI - Python Tkinter)

A simple beginner-friendly **Login & Signup desktop application** built using Python and Tkinter.  
This project uses a clean blue-themed GUI and stores user data in a local text file.

---

## 🚀 Features

- Signup new users
- Login existing users
- Simple and clean GUI interface
- Blue modern theme design
- Data stored in `users.txt`
- Beginner-friendly Python code (no advanced libraries)

---

## 🖥️ Technologies Used

- Python 3
- Tkinter (GUI library)
- File handling (users.txt)

---

## 🎨 UI Theme

This project uses a **blue color theme**:

- Background: Light Blue (`#eaf6ff`)
- Card: White (`#ffffff`)
- Primary Blue: (`#5fa8d3`)
- Text: Dark Blue (`#1b4965`)
